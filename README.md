<h2>Steps to Run This Project</h2>

<ol>
  <li>Clone the repository</li>
  <li>Add env variables in backend;
    <ol>
      <li>PORT</li>
      <li>MONGO_URI</li>
      <li>JWT_SECRET</li>
      <li>CLOUDINARY_CLOUD_NAME</li>
      <li>CLOUDINARY_API_KEY</li>
      <li>CLOUDINARY_API_SECRET</li>
    </ol>
  <li>Open two terminals - one for the backend and one for the frontend</li>
  <li>Run <code>npm install</code> in both terminals</li>
  <li>Run <code>npm run dev</code> in both terminals</li>
</ol>
